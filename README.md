# Conformia — Groq (100% gratuit)

## 1. Obtenir ta clé Groq GRATUITE
- Va sur https://console.groq.com
- Crée un compte
- Clique sur "API Keys" puis "Create API Key"
- Copie la clé

## 2. Coller ta clé dans le terminal
Dans le terminal, dans ce dossier, tape :
  Set-Content .env.local "GROQ_API_KEY=TACLÉ"
(remplace TACLÉ par ta vraie clé)

## 3. Installer et lancer
  npm install
  npm run dev

## 4. Ouvrir dans Chrome
  http://localhost:3000
